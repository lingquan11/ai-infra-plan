## 任务一：提交第一个开源 PR

**目标**：把学到的东西贡献回社区。

**步骤**

1. 在选定方向的项目中找 good first issue、文档错误或缺失的 benchmark
2. 先在 issue 下留言认领
3. 按项目的 CONTRIBUTING 说明配置开发环境，跑通测试
4. 提交一个小而完整的 PR（附测试或数据），根据 review 修改

**验收**

- ✅ 至少提交一个 PR（被合并更好）
