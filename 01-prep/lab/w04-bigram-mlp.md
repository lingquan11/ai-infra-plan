# 第 4 周：语言模型入门：bigram 与 MLP

> 课程：Karpathy makemore 第 1–2 集 ｜ 预计用时：10–12h
> 本周产出：能生成名字的 MLP 语言模型

先读：[本周讲义](../lecture/README.md#w04)

## 任务一：bigram 字符语言模型

**目标**：理解语言模型就是在预测下一个 token 的概率分布。

**步骤**

1. 下载 makemore 仓库中的 names.txt（约 3 万个英文名）
2. 统计所有相邻字符对的出现次数，归一化成概率表，从中采样生成新名字
3. 计算整个数据集的平均负对数似然（NLL）作为 loss
4. 改成神经网络版本：字符 one-hot 乘以权重矩阵 W，softmax 得到概率，用梯度下降最小化 NLL
5. 比较两种方法的 loss

**验收**

- ✅ 神经网络版的 loss 接近计数法的 loss
- ✅ 能生成看起来像名字的字符串

## 任务二：MLP 字符语言模型

**目标**：用嵌入向量和隐藏层，让模型看到更长的上下文。

**步骤**

1. 用前 3 个字符预测下一个字符，构造训练样本
2. 实现嵌入表 C、tanh 隐藏层和输出层，手写前向
3. mini-batch 训练，并做学习率搜索（按指数间隔试一遍，看 loss 曲线）
4. 把数据分成训练、验证、测试三份，观察过拟合
5. 把二维嵌入画出来，看看哪些字符聚在一起

**验收**

- ✅ 验证集 loss 明显低于 bigram
- ✅ 能解释训练集 loss 和验证集 loss 之间差距的含义
